# 数字货币清算知识图谱

一个用资金瀑布解释数字货币合约清算过程的公开知识页面。

页面以币安公开规则为核验样本，依次说明：

- 客户权益如何承担市场亏损
- 标记价格、强平与 IOC 甩单
- 穿仓和保险基金
- 保险基金的分类与公开数据入口
- ADL 的触发条件、排序公式和执行结果
- 普通现货、现货杠杆与合约清算的区别
- 哪些说法已经证实，哪些仍缺少公开数据

## 打开页面

直接打开 `index.html`，或启用 GitHub Pages 后访问仓库主页。
